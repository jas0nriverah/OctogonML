Create a pre-event forecast batch Open editor +

Use a verified future fixture and its scheduled time. Copy the scenario selected in Forecast Explorer, review the JSON, and submit. Saving records a local forecast; it does not submit a wager or schedule an automated task.

Each fixture needs a unique fixture_id, future scheduled_at (ISO 8601 with timezone), event_date, known fighter_id and opponent_id, scheduled_rounds, line, line_kind (actual_user or synthetic), schedule_kind, and a public source_url. The builder marks schedules user_attested: a supplied URL is not independent verification. Reusing the same idempotency key safely retries the same batch.
