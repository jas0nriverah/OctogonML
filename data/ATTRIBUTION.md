# Data attribution

Historical base: Noah Bair, UFC Data v0.1.1 (2026), https://doi.org/10.5281/zenodo.23458636, CC BY 4.0: https://creativecommons.org/licenses/by/4.0/. Underlying sources: UFCStats, MMA Decisions, BestFightOdds, martj42 official ranking archive, UFCalendar.

October 17 increment: Greco1899/scrape_ufc_stats, https://github.com/Greco1899/scrape_ufc_stats, repository license GPL-3.0; original license preserved in [licenses/GPL-3.0.txt](licenses/GPL-3.0.txt) and in the raw download cache. The historical source notice is [licenses/CC-BY-4.0-notice.txt](licenses/CC-BY-4.0-notice.txt). No scraper code copied.

Changes: normalized schema, exact identity mappings, round aggregation, standard-format filtering, NC/overturned exclusions, lagged features. Raw snapshots, original license texts, commit IDs, URLs and SHA256 hashes are preserved. Collected after events; recent predictions are reconstructed historical inference. Independent project, not affiliated with the source providers.

Announced schedules and athlete portraits: ESPN's public UFC scoreboard and athlete-profile APIs, observed October 22, 2026. The requested schedule window is October 22–December 31, 2026. Original JSON responses, retrieval timestamps, URLs and SHA256 digests are preserved under `data/schedules/`; these records describe the published schedule at retrieval, and bookings can change. Card/segment start times are not individual walkout times.

Portraits are original headshot URLs returned by ESPN athlete profiles, referenced directly from ESPN's CDN with attribution. No image file is downloaded, rehosted, generated or claimed as original project artwork. Photo availability does not establish a verified model identity. ESPN/UFC names and media retain their respective ownership. See `data/fighter_photos.json` and `data/schedules/provenance.json` for per-athlete source links and credits. Offline or unavailable photos fall back to initials.

The broader fighter directory additionally uses ESPN's public MMA player-search API, with athlete-profile fallback, observed October 22, 2026. Matching requires a unique exact normalized canonical name, an ESPN MMA UID and profile ID, an observed individual ESPN CDN headshot URL, and a successful image header check. The 1,844 verified portraits preserve the original 134 entries. The remaining 230 canonical fighters retain explicit unavailable-photo status: 93 profiles without a verified portrait, 135 without a unique exact source match, and two ambiguous local names. Original compact source responses, observation times, and hashes are retained in `data/fighter_profiles/espn_player_search.jsonl.gz`; [coverage.json](fighter_profiles/coverage.json) records the source policy and counts. No portrait is a model feature.
