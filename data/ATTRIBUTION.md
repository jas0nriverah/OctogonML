# Data attribution

Historical base: Noah Bair, UFC Data v0.1.1 (2026), https://doi.org/10.5281/zenodo.23458636, CC BY 4.0: https://creativecommons.org/licenses/by/4.0/. Underlying sources: UFCStats, MMA Decisions, BestFightOdds, martj42 official ranking archive, UFCalendar.

October 17 increment: Greco1899/scrape_ufc_stats, https://github.com/Greco1899/scrape_ufc_stats, repository license GPL-3.0; original license preserved under raw/Greco1899/LICENSE. No scraper code copied.

Changes: normalized schema, exact identity mappings, round aggregation, standard-format filtering, NC/overturned exclusions, lagged features. Raw snapshots, original license texts, commit IDs, URLs and SHA256 hashes are preserved. Collected after events; recent predictions are reconstructed historical inference. Independent project, not affiliated with UFC or PrizePicks.
